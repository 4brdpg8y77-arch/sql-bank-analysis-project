# SQL Bank Analysis Project

## Project Overview

This project demonstrates my ability to use PostgreSQL to analyze banking data and answer real-world business questions.

The analysis focuses on customer segmentation, loan performance, credit risk, transaction activity, customer behavior, and financial trends. The project contains 15 SQL analyses ranging from aggregation and filtering to more advanced analytical techniques.

## Business Questions

1. How do average income and credit scores vary across customer segments?
2. How are loans distributed across different loan types?
3. How does loan status affect overall credit risk?
4. What is the credit risk profile for each loan status?
5. Which loans represent the highest risk exposure?
6. Which customers have the highest loan burden?
7. How do interest rates vary by loan type and loan status?
8. How does loan origination change over time?
9. How do customers rank based on their loan activity?
10. Which customers present the highest credit risk?
11. How does customer transaction activity vary?
12. How do customers rank based on monthly transaction activity?
13. Which customers have transaction activity above the overall average?
14. Who are the top customers for each loan type?
15. Which high-value customers also present significant credit risk?
